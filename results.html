최장 멜로디 검색

문제 정의순차 배열정렬 배열체이닝 해시결과와 비교부록: 전체 결과표
결론검색: 데이터 크기별이론과 실측구축 비용메모리언어별 성능 차이Python이 느린 이유어떤 걸 고를까

실험 결과와 비교

C++·Python 실측. 데이터 수 N(항목) 1천~100만. 입력 16칸, 유형마다 질의 50개, 반복 측정 중앙값.

결론: 가장 빠른 검색은 입력 종류에 따라 다르고, 균형은 정렬 배열

    데이터 크기별 검색 시간

    순차 배열정렬 배열체이닝 해시세로축은 10배씩 커지는 로그 눈금(점선은 2배·5배), 그래프마다 눈금 범위 다름

    DB에 있는 곡 (수록곡)

    • 순차 배열: 데이터 규모에 비례하여 검색 시간이 증가함.
    • 정렬 배열·체이닝 해시: 데이터가 100만 개까지 증가해도 검색 시간이 거의 일정함. C++는 정렬 배열이 가장 빠르고(0.54µs), Python은 두 방식이 유사함(약 30µs).

    DB에 없는 곡 (미수록곡)

    • 순차 배열: 데이터 규모에 비례하여 검색 시간이 증가함.
    • 정렬 배열·체이닝 해시: 두 언어 모두 1천~5천 항목에서 1만 항목보다 검색 시간이 길며, 체이닝 해시가 정렬 배열보다 조금 빠름.
    • 원인: 데이터가 적을 때는 최장 일치 길이가 짧아 비교 후보가 많음(약 2,100쌍). 1만 항목부터는 최장 일치 길이가 증가하면서 후보 수가 50~300쌍으로 감소.
    • 2천 항목 이하(점선 박스): C++는 단순 반복이 빨라 순차 배열이 가장 빠르지만, Python은 반복 연산의 부담이 커 비교 횟수를 줄이는 색인 기반 검색이 더 빠름. 언어별 연산 비용에 따라 효율적인 자료구조가 달라질 수 있음.

    이론(빅O)과 실측 비교: 검색 시간 증가율 (DB에 있는 곡)

    순차 배열 O(N)정렬 배열 O(log N)체이닝 해시 O(1)

    자료구조시간 복잡도이론적 증가율C++ 실측Python 실측
    순차 배열O(N)1,000배964배1,111배
    정렬 배열O(log N)약 2배1.97배1.57배
    체이닝 해시평균 O(1)1배1.08배1.03배

    1천 항목 대비 100만 항목에서의 검색 시간 증가율. 이론적 증가율은 각 복잡도의 대표 함수를 기준으로 산출함.

    • 이론과 실측의 차이: 세 방식 모두 이론과 유사한 증가 양상을 보임. 다만 C++에서는 정렬 배열이 체이닝 해시보다 실제 검색 시간이 짧음. 정렬 배열은 입력 전체가 일치하면 추가 길이 탐색이 불필요하지만, 체이닝 해시는 입력 멜로디의 부분 조각에 대한 해시값을 매 검색 시 사전에 계산하는 오버헤드가 발생함.
    • 검색 시간의 변동: 데이터 규모별로 서로 다른 50개의 질의를 사용하므로, 질의마다 비교 후보 수와 일치 곡 수가 달라 검색 시간이 변동할 수 있음.
    • DB에 없는 곡: 정렬 배열과 체이닝 해시는 소규모 데이터에서 오히려 검색 시간이 길어 이론과 다른 양상을 보임.

    구축 비용 (100만 항목)

    순차 배열은 별도의 색인 구축이 필요하지 않음.

    막대마다 아래에 언어 표시 (진한 막대 C++, 옅은 막대 Python) · 로그 눈금

    • 구축 시간: 체이닝 해시는 정렬 배열보다 구축 시간이 길게 나타남(C++ 6.3배, Python 1.3배).
    • 원인: 정렬 배열은 각 항목의 시작 위치를 정렬하지만, 체이닝 해시는 DB 전체에 대해 길이 1~32의 부분 조각별 해시값 계산 및 버킷 구성이 필요함.
    • 비용 대비 효율: 검색 횟수가 적을 경우 구축 비용이 낮은 정렬 배열이 유리함. 반면 색인을 지속적으로 재사용하는 환경에서는 일회성 구축 비용의 상대적 중요도가 낮아지므로 검색 성능이 더 중요한 판단 기준이 됨.

    메모리 사용량 (100만 항목)

    막대마다 아래에 언어 표시 (진한 막대 C++, 옅은 막대 Python) · 로그 눈금 · 원곡 데이터는 프로세스 메모리(RSS), 색인은 C++ 힙·Python getsizeof

    • 언어별 메모리 차이: 원곡 데이터·정렬 배열은 C++가 vector<int>(값만 4바이트), Python이 list(칸마다 포인터 8바이트 + int 객체)를 써서 Python이 3~9배 크고, 해시는 Python도 array("i")를 써서 C++와 같음.
    • 자료구조별 메모리 차이: 체이닝 해시가 정렬 배열보다 많은 메모리를 사용함(C++ 약 82배). 정렬 배열은 시작 위치마다 번호 하나만 저장하지만, 체이닝 해시는 길이 1~32의 부분 조각을 모두 색인하므로 동일한 시작 위치가 최대 32번 저장되며, 해시값과 버킷 정보도 추가로 저장하기 때문임.

    언어별 성능 차이 (100만 항목 검색 시간)
