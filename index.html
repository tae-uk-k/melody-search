최장 멜로디 검색

문제

원곡 멜로디 데이터와 입력 멜로디 하나가 주어짐. 입력과 원곡 사이의 최장 공통 부분 문자열의 길이, 그리고 그 길이로 일치하는 곡을 모두 구하는 문제. 단, 키와 빠르기가 달라도 같은 멜로디로 판정.

길이가 같은 두 구간은 아래 세 조건을 모두 만족하면 같은 멜로디.

  1. 같은 위치끼리 음과 쉼의 종류가 같음.
  2. 같은 위치의 음끼리 높이 차이가 구간 전체에서 일정함. 키 변경 허용.
  3. 같은 위치끼리 길이 비율이 구간 전체에서 일정함. 빠르기 변경 허용.

구간 길이는 음과 쉼의 개수. 쉼도 한 칸.

음 높이 대신 변화량으로 비교

음마다 바로 앞 음과의 높이 변화, 길이 비율만 봄. 키를 올리거나 느리게 불러도 변화량은 그대로라 같은 멜로디로 판정.

정렬 배열과 체이닝 해시는 이 변화량을 번호 하나로 바꿔 미리 저장. 순차 배열은 저장 없이 비교할 때마다 계산.

입력

원곡 데이터는 파일에서 읽음. 파일은 블록의 반복이고, 블록마다 첫 줄에 곡명, 둘째 줄에 항목 수 n, 다음 n줄에 음 높이 p와 길이 d.

사용자 입력은 첫 줄에 항목 수 r, 다음 r줄에 음 높이 p와 길이 d. p가 -1이면 쉼.

서로 다른 블록은 이어 붙이지 않음. 곡명이 같은 블록은 같은 곡으로 처리.

출력

첫째 줄에 최대 일치 길이: L, 둘째 줄에 일치한 곡 (k곡), 다음 k줄에 길이 L로 일치하는 곡명을 중복 없이 사전 순으로 출력. 실행 시간 줄은 생략.

제한

  • 1 ≤ r ≤ 32
  • p = -1 또는 0 ≤ p ≤ 127 (MIDI 음 높이)
  • d는 양의 정수. 최댓값 4,294,967,557로 32비트 범위 초과, 64비트 정수 필요
  • 블록 길이 n ≤ 7,425
  • 전체 데이터: 블록 310,265개, 항목 30,477,226개 (Lakh MIDI 단선율 구간)

힌트

입력의 2~8번째 음은 반짝반짝 작은 별 전체를 7만큼 높이고 길이를 2배로 늘린 멜로디. ABC 노래는 반짝반짝 작은 별을 5만큼 높인 멜로디라 함께 일치.
